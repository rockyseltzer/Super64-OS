Cheat code files are placed in this folder.
Codes are in GameShark format (also used by Action Replay and Equalizer).

One file per game: ED64P/CHEATS/<ROM name>.txt
One code per line:   AAAAAAAA VVVV description
Disabled codes start with #:   #AAAAAAAA VVVV description
Up to 34 codes.

The game's ROM Config > Use Cheats must be On and an Expansion Pak inserted for codes to be applied.

The .txt files in this folder are samples, and each must have the same name as its ROM file. Most codes in them are enabled; a few that change the game drastically (such as level select or always finishing first) are disabled. To turn a code on or off, use the Cheat Code Editor (File Menu > ROM Config > Cheat Editor) or add or remove the # in front of the line.
